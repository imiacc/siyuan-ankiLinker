# siyuan-ankiLinker

[English](./README.md)

思源笔记闪卡同步 Anki 插件。

- 作者：`imiacc`
- 仓库：<https://github.com/imiacc/siyuan-ankiLinker>
- 当前版本：`0.1.1`

## 功能

- 手动触发将思源闪卡同步到 Anki。
- 维护思源闪卡与 Anki 卡片的稳定映射关系。
- 支持增量新增、增量修改、增量删除。
- 支持问答卡与填空卡分开指定模板。
- 支持自动读取所选 Anki 模板的字段列表，并通过下拉框选择字段。
- 支持按思源文档路径前缀，把不同文档/目录下的闪卡同步到不同 Anki 卡组。
- 提供同步预览、同步日志、本地映射持久化。

## 闪卡识别逻辑

当前版本支持以下思源闪卡形式：

### 1. 问答卡

支持两种：

- 单块中使用 `---` 或 `***` 分隔正反面
- 父块/超级块问答：第一个子块作为正面，其余子块合并为背面

### 2. 填空卡

使用思源高亮语法：

```md README_zh_CN.md
地球离太阳最近的行星是 ==水星==。
```

会转换为 Anki Cloze：

```text README_zh_CN.md
地球离太阳最近的行星是 {{c1::水星}}。
```

## 同步方向与删除规则

### 思源 → Anki

本插件是 **单向同步**：

- 思源中的闪卡新增，会在 Anki 新增笔记
- 思源中的闪卡内容变化，会更新 Anki 对应笔记
- 思源中的闪卡不存在后，会删除 Anki 中对应笔记

### Anki → 思源

不会反向改写思源内容：

- 你在 Anki 中修改笔记字段，不会写回思源
- 你在 Anki 中删除某张笔记，不会删除思源中的块内容
- 但下次同步时，如果思源里该闪卡仍存在，插件会尝试重新创建或重新建立映射

## 路径分卡组逻辑

插件会读取每张闪卡所属块的文档路径（hPath），并按你配置的“路径前缀 → 卡组”规则匹配。

例如：

- `/英语/词汇` → `English::Vocab`
- `/数学/线代` → `Math::LinearAlgebra`

匹配规则为 `startsWith`：

- 如果路径命中规则，则同步到该规则指定卡组
- 如果没有命中任何规则，则同步到“默认目标卡组”

建议：

- 用较稳定的目录前缀配置规则
- 规则尽量不要重叠太多
- 若多个规则可能同时命中，当前按配置顺序取第一个命中项

## 模板与字段选择

插件不会再假定模板字段一定是：

- 问答：`Front / Back`
- 填空：`Text / Extra`

现在会：

1. 读取你选择的 Anki Note Type
2. 自动读取该模板的字段列表
3. 在插件中以下拉框方式让你选择字段

这可以避免因为手填字段名错误导致：

- `cannot create note because it is empty`

## 使用步骤

1. 启动本地 `Anki Desktop`
2. 确认它已登录并可同步到你的 Anki Server
3. 安装并启用 `AnkiConnect`
4. 在插件中点击“检测本地连接”
5. 点击“刷新卡组/模型”
6. 选择默认卡组
7. 选择问答模板、填空模板
8. 从下拉框选择模板字段
9. 如有需要，配置“路径前缀 → 卡组”规则
10. 点击“生成同步预览”
11. 检查预览详情与无效原因
12. 点击“执行同步”
13. 如需上传到远端服务器，再回到 Anki 执行正常同步

## 预览说明

同步预览分为：

- 新增
- 更新
- 删除
- 无效

预览详情支持：

- 展开/收起
- 固定高度滚动

无效卡通常表示：

- 问答卡正反面为空
- 填空未生成有效 Cloze 语法
- 模板字段未配置完整
- 当前块未识别为支持的闪卡格式

## Markdown 保留策略

- 以思源块的 Markdown/kramdown 内容作为同步基础
- 不主动转换为 HTML 后再回写
- 公式、列表、引用等尽量保留原始结构
- 是否正确显示，最终取决于你的 Anki 模板与渲染插件

## 推荐搭配的 Anki 插件/方案

### 必装

- `AnkiConnect`

### 推荐

- Markdown / KaTeX 渲染类插件
- 兼容你字段结构的自定义 Note Type

## 卸载清理说明

插件完整卸载时，会清理自己在思源插件数据目录下创建的持久化文件，包括：

- `settings.json`
- `mappings.json`
- 旧版遗留 `ankilinker-state.json`

注意：

- 只有“完整卸载”才会执行这部分清理
- 普通禁用、重载、升级不会删除你的配置，避免误丢数据

```powershell README_zh_CN.md
D:\Environment\nodejs22\npx.cmd vite build
```

- `dist/`
